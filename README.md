# ✨ Overview

Ignitia 2K25 is a **fully designed and developed frontend web experience** inspired by the spirit of **PSIT's annual techno-cultural festival**.

Rather than simply recreating a webpage, this project focuses on delivering a premium digital experience through **modern UI design**, **cinematic animations**, **interactive navigation**, and **high-performance React architecture**.

Built completely from scratch using **React**, **Tailwind CSS**, **GSAP**, and **Vite**, the project demonstrates component-driven development, reusable architecture, responsive design, and smooth user interactions suitable for modern production-grade frontend applications.

# 🌟 About the Project

Ignitia is the flagship annual techno-cultural festival of **Pranveer Singh Institute of Technology (PSIT)**, bringing together innovation, technology, culture, creativity, and entertainment.

This project is an independently developed frontend implementation that showcases how a large-scale event website can be built using modern frontend technologies and industry-standard development practices.

The emphasis was placed on creating an engaging user experience through fluid animations, modular React components, responsive layouts, and optimized rendering.

Unlike traditional static event websites, this project integrates interactive UI patterns, reusable architecture, and seamless transitions to deliver a polished browsing experience across all devices.

# 🚀 Getting Started

## Prerequisites

Before running the project, make sure you have installed:

- Node.js (v18 or above recommended)
- npm

---

## Installation

Clone the repository

```bash
git clone https://github.com/AyushAwasthi26/Ignitia.git
```

Navigate into the project directory

```bash
cd Ignitia
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```

---

# 📦 Production Build

Create a production build

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
